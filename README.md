# 로트발트의 왕관 (폰 앱)

서버 없이 폰 브라우저 안에서 전부 돌아가는 버전. 폰이 Claude·GPT API를 직접 부르고, 세계는 폰 안에 저장된다.

## 설치 (한 번만)

앱 파일을 HTTPS 주소에 올려야 홈 화면 설치가 된다. 가장 쉬운 건 GitHub Pages.

1. GitHub에서 새 저장소를 만든다 (예: `rotwald`, Public).
2. 이 폴더의 파일을 전부 올린다 (Add file → Upload files로 끌어다 놓기).
3. Settings → Pages → Branch를 `main`, 폴더 `/ (root)`로 두고 Save.
4. 1~2분 뒤 `https://(아이디).github.io/rotwald/` 가 열린다.
5. 폰 크롬으로 그 주소를 열고, 메뉴(⋮) → **홈 화면에 추가**(또는 **앱 설치**).

주소가 공개돼도 괜찮다. 키는 각자의 브라우저에만 저장되므로, 남이 열면 그 사람은 자기 키를 넣어야 한다.

## 처음 실행

오른쪽 위 **설정**에서 Anthropic, OpenAI 키를 넣고 저장. 키를 비워 둔 쪽은 모의 응답으로 돌아가서 공짜로 화면만 구경할 수 있다.

## 지도

- 왕국은 16개 주, 46개 영지로 나뉜다. 영주는 영지 단위로 땅을 가지고, 전쟁도 영지 하나를 놓고 벌인다.
- 정착지: 마을(●, 1천 미만) · 소도시(□, 1천~5천) · 중도시(▣, 5천~1만5천) · 대도시(◉, 1만5천 이상). 인구는 계절마다 개발도·지형·전쟁·계절에 따라 변하고, 100명 아래로 떨어지면 폐허가 된다. 평화로운 영지에는 가끔 새 마을이 생긴다.
- 두 손가락으로 확대, 확대한 뒤 한 손가락으로 이동. 확대할수록 작은 정착지 이름까지 보인다. 영지를 누르면 정착지 목록이 나온다.

## 점령과 반란

- 전쟁에서 이기면 목표 영지를 먼저 **점령**한다. 지도에 점령 세력의 색으로 빗금이 쳐지고, 그 영지의 세금 일부가 점령자에게 간다. 전황이 +3이 되면 병합되고, 0 이하로 밀리면 점령이 풀린다.
- **반란**은 판관이 일으키거나(학정·기근·역병 뒤), 위신이 바닥이거나 전쟁·재앙에 지친 영지에서 저절로 터진다. 반란군 점령지는 검은 빗금. 영주가 군대를 소집해야 제대로 진압할 수 있고, 반란 기세가 +3이 되면 반란 지도자가 그 땅의 새 영주가 된다.
- 신의 권능 탭에서 원하는 영지에 반란을 일으킬 수 있다.

## 쓸 때 알아 둘 것

- 한 계절에 30초에서 1분쯤 걸린다(판관이 가장 오래 걸림). 그동안 화면은 자동으로 켜져 있지만, **다른 앱으로 넘어가면 그 계절이 끊길 수 있다.** 끊기면 그 계절은 없던 일로 되돌아가고, 이미 쓴 토큰 비용만 기록에 남는다.
- 세계는 매 계절 자동 저장된다. 크롬의 사이트 데이터를 지우면 같이 사라지니, 가끔 **설정 → 세계 내보내기**로 파일을 받아 두자.
- 지출 막대는 추정치이고, 매달 1일에 자동으로 0이 된다. 예산을 넘으면 자동 진행이 멈춘다.
- 모델 ID나 추론 강도는 설정에서 바꿀 수 있다.

## 파일

- `index.html`, `style.css`, `app.js` 화면
- `engine.js` 게임 엔진, API 호출, 모의 응답
- `data.js` 시작 세계, 프롬프트, 기본 모델과 단가
- `manifest.webmanifest`, `sw.js`, 아이콘 — 홈 화면 설치와 오프라인 열기
